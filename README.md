# 🌍 Travel Landing Page

This project is a **responsive travel landing page** built with **HTML** and **CSS**.  
It features a hero image with overlapping animated text effects, creating a modern, dynamic design to attract visitors.  

---

## 📊 Project Overview

The webpage includes:
- **Hero Section** with a full-width background image  
- **Scrolling Text Animations** to highlight travel-themed words  
- **Overlayed Typography** for visual depth and impact  
- Fully responsive layout that adapts to various screen sizes  

---

## 🧰 Tech Stack

- **HTML5** — Structure of the landing page  
- **CSS3** — Styling, positioning, and animations  
- **Google Fonts (Rubik)** — Modern typography  
- **CSS Animations & Keyframes** — For scrolling and visual effects  

---

## 🚀 Features

1. **Animated Scroll Text**  
   - Multiple layers of text moving in different directions and speeds  
   - Transparent stroke effect for one of the layers  

2. **Hero Image**  
   - Full-width image creating a strong visual focal point  

3. **Responsive Design**  
   - Layout adjusts to screen sizes  
   - Scrollbars hidden for a cleaner look
